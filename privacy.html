개인정보처리방침

해원이 다녀온 그날(이하 "채널")은 유튜브 채널 운영을 위해 Google 계정 로그인(OAuth)을 사용합니다. 이 로그인은 채널 운영자 본인의 계정에만 쓰입니다.

  • 접근하는 정보: 운영자 채널의 영상 업로드, 영상 정보 수정, 채널 분석 수치
  • 이용 목적: 운영자 채널에 영상을 올리고 관리하는 것에 한정합니다
  • 제3자 제공: 하지 않습니다
  • 시청자 개인정보: 수집하지 않습니다
  • 보관과 삭제: 인증 정보는 운영자 기기에만 보관하며 Google 계정 설정에서 언제든 접근 권한을 해제할 수 있습니다

Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(Limited Use 요구사항 포함)를 따릅니다.
